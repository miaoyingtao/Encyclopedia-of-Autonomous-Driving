feat(adsim): add a real closed-loop autonomy stack with a browser lab

A working autonomous-driving pipeline that actually runs, not an animation:

  assets/adsim/core/math.js        vectors, geometry/SAT, quintic, Hungarian, seeded RNG
  assets/adsim/core/world.js       kinematic bicycle model + actuator lag, IDM traffic
  assets/adsim/core/perception.js  ray-cast lidar, distance clustering, PCA boxes,
                                   constant-velocity Kalman filter + Hungarian association
  assets/adsim/core/prediction.js  CTRV rollouts, multi-modal intents, occupancy footprints
  assets/adsim/core/decision.js    FSM (cruise/follow/lane-change/yield/stop/emergency)
                                   with hysteresis, TTC and gap-latch logic
  assets/adsim/core/planning.js    Frenet sampling (5 lateral x 4 speed), collision
                                   checking, multi-objective cost, best-trajectory pick
  assets/adsim/core/control.js     Pure Pursuit (adaptive lookahead) + PID with anti-windup
  assets/adsim/core/metrics.js     collision/gap/TTC/accel/jerk/track-error scoring
  assets/adsim/core/sim.js         20 ms closed loop with per-module timing
  assets/adsim/scenarios.js        cut-in, pedestrian crossing, work-zone narrowing
  assets/adsim/selftest.js         65 module and scenario assertions (fixed seed)
  assets/adsim/run.js              Node CLI: batch scenarios + metric report
  assets/adsim/ui.js + adsim.css   Canvas 2D view with layer toggles and live panels

Ground truth isolation is enforced: decision and planning only consume track and
prediction outputs; truth is used for lidar simulation and scoring only.

build.py gains three optional front-matter keys (layout: full, styles, scripts) so
a page can host custom scripts; the new pages/adsim.html uses them.

Verified: build --check -> 40 cards / 40 topics, 0 errors, 0 warnings;
check_links --root site -> 44 pages, 0 errors, 0 warnings;
node assets/adsim/selftest.js -> all module assertions pass;
node assets/adsim/run.js -> three scenarios pass (see report).
