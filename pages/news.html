本页是什么？怎么维护？

读者视角：本页收录与本站教程主题强相关的行业事件（重点覆盖 LLM / VLA、世界模型、L3 准入、Robotaxi 等前沿话题）。每条动态都给出摘要与原文链接，方便继续深读对应的系统教程章节。

维护者视角：本站是纯静态部署，不需要数据库或后台。动态数据存在 assets/news-data.js，推荐运行 python tools/news_fetcher.py 自动抓取：每次运行会用最新结果替换旧自动条目，并只保留最新 30 条（数量在 tools/news_sources.json 的 maxTotal 配置），更旧的自动删除；链接与相似标题自动去重。如需个别置顶内容也可手工追加。本地运行 python tools/serve.py 后访问 http://127.0.0.1:8765/pages/news.html，列表右上角“🔄 刷新动态”按钮即可一键抓取并自动重载。页面每次打开自动按日期倒序渲染，详见页面底部说明。

本页如何自动保持最新

本页内容来自 assets/news-data.js，页面每次打开都会重新读取渲染，无需改 HTML。保持更新推荐“自动抓取”，也可随时手工补充。

方式一：自动抓取资讯（推荐）

  1. 配置资讯源

    编辑 tools/news_sources.json：内置了按“自动驾驶综合 / 世界模型与大模型 / L3 与准入 / Robotaxi”四组中文检索词自动生成新闻源的配置，也可直接加 RSS/Atom 订阅地址（如 Waymo 官方博客）。关键词过滤与分类规则都在该文件调整。

  2. 运行一次抓取

    在项目根目录执行 python tools/news_fetcher.py。脚本会联网拉取新闻、关键词过滤、去重、自动分类（政策与准入 / 技术与研究 / 量产车型 / 出行运营 / 行业动态）并重写 assets/news-data.js。；或先运行 python tools/serve.py，再点本页“🔄 刷新动态”按钮，效果相同。

  3. 设置定时任务（可选）

    用 Windows 任务计划程序每天定时运行 tools/update_news.ps1 即可无人值守更新；命令行与步骤见 tools/README.md。自动更新会整段替换为最新条目并只保留 30 条：更早的手工或自动条目都会被移出列表。

方式二：手工补充一条（可选）

  1. 打开数据文件

    编辑 assets/news-data.js，在数组末尾、最后一个对象之后加英文逗号再粘贴新对象。

  2. 填写字段

    字段含 date（YYYY-MM-DD）/ title / summary / link / source / category / tags。分类取值：政策与准入、技术与研究、量产车型、出行运营、行业动态。若希望某条显示“★ 精选”角标，可加 "featured": true。

  3. 保存并刷新

    保存后重新打开本页或首页，新条目会自动出现；自动抓取运行时会保留这条手工记录。

写摘要与选源的小建议

自动抓取会产生摘要与标签，重要事件建议仍以原文链接为准；若自动分类不准，可在 tools/news_sources.json 的 categoryHint 中给资讯源指定默认分类。列表条数上限见 network.maxTotal；同事件去重配置在 dedupe（相似度阈值、跨天窗口 fuzzyDays、品牌/中英别名 aliases）；featured 用于“★ 精选”自动标记的关键词与条数上限。刷新按钮和命令行都会套用这些规则，覆盖旧的自动条目并删除重复。
