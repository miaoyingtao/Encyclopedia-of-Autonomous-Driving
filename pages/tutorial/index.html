01

这套教程怎么读

本站内容分两层。科普篇（核心技术、应用场景等）回答“是什么、为什么”，帮你建立地图；教程篇（本目录以下各章）回答“公式是什么、代码怎么写、坑在哪里”。建议流程：先在 核心技术 花 10 分钟看全景，再按路径进入各章。

每一章都遵守同一份讲义结构，方便你系统对照：

  1. 学习目标与前置

    开头明确“学完能干什么”与“需要会什么”，缺的数学在 01 章补齐。

  2. 原理与数学建模

    核心公式逐行给出含义，不跳步：每个变量是什么、量纲是什么、为什么这样近似。

  3. 算法与流程

    用文字步骤 + 伪代码给出可复现的算法骨架，而不是只贴结论。

  4. 工程要点与坑

    时序、同步、数值、标定、算力等真实系统才会遇到的问题。

  5. 自测题

    每题对应一个小知识点，答案折叠在题后，先自己写再看。

推荐姿势

准备纸笔：每一章把公式自己推导一遍、把伪代码翻译成 Python 或 C++ 草稿。看懂的标志是你能在不看原文的情况下，把一个传感器数据流从头到尾“讲”成代码模块。

想进功能安全、测试评价：先通读 3 章，再横跳 安全体系 与 测试评价，最后回头精读 2 章看安全层如何“罩住”算法。

04

全书统一的记号与坐标约定

记号含义说明
x, u, z状态、控制输入、观测x 表示被估计或待规划的量
R, t, T旋转矩阵、平移向量、齐次变换矩阵T = [R | t; 0 1]，见第 0 章
P, Q, R协方差、过程噪声、观测噪声矩阵大写，量纲随状态而定
K卡尔曼增益衡量“信观测还是信预测”
θ, δ, v, a航向角、前轮转角、速度、加速度车体模型常用变量
w, l, h目标宽度、长度、高度3D 框参数

坐标约定全书统一：世界系取右手直角系（东 x、北 y、天 z 的 ENU 或近似路面坐标系）；车体系取 x 指前、y 指左、z 指上（ISO 8855 风格）。阅读论文遇到不同约定时，先花一分钟对齐坐标轴，90% 的“公式对不上”都源于此。

05

常见疑问

数学基础一般，能跟上吗？

可以。第 0 章把后续要用的矩阵、概率、优化全部过一遍并标注用途；若遇到完全陌生的概念，先跳过符号、抓住“这个公式在解决什么问题”，回头再补推导。

只有公式没有代码，怎么算教程？

每章给出可运行思路的伪代码与参数表；算法类题目强烈建议对照伪代码用 Python + NumPy 复现一次——多数自动驾驶算法的最小原型只需要几十行。

教程与科普页会重复吗？

不重复：科普页管“概念与语境”，教程页管“建模与实现”，两者互链。想快速了解某个词，看科普；想弄懂某个算法，进教程。

更新到“大模型/世界模型”了吗？

最新方向先由 AI 前沿专题 承担概念部分；教程第 1、3 章已预留与其衔接的训练数据、评测与安全章节，可在读完 0–3 章后综合理解。

现在开始

如果你第一次接触，先完成第 0 章；如果只想补某一环，可直接跳对应章节，页内会给前置指引。
