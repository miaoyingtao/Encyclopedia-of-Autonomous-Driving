控制执行 Control

大脑想好了“怎么开”，最后必须由“手脚”精确执行：方向盘打多少、制动踩多深、电门给多大。控制执行决定了一辆自动驾驶车是“开得顺”还是“开得毛”，也是“停得住”的最后防线。

01

控制层在整个链条中的位置

完整链路是：感知 → 决策与规划 →（轨迹）→ 控制 →（指令）→ 执行器 → 车辆运动。其中：

  • 规划层输出的是“参考轨迹”：每一时刻期望的位置、速度、朝向（例如“0.5 秒后应到 x=3.2m，车速 8m/s”）；
  • 控制层实时计算“现在该打多少方向、踩多少刹车”，去逼近这条轨迹；
  • 执行层（线控底盘）把电信号变成真实的转向角、制动力与驱动扭矩；
  • 车辆运动后，传感器又测出实际位置偏差，反馈回控制器——形成一个每秒数百次校正的闭环。
为什么说“控制决定上限的感觉”

同样一条规划轨迹，控制得好则车身平稳、乘员无感；控制得差则来回修正、忽快忽慢。乘客对自动驾驶“像不像老司机”的体感，很大程度来自控制层。

02

线控底盘：自动驾驶的“硬件前提”

传统汽车靠机械/液压连接传递驾驶指令；自动驾驶则要求电信号直接控制执行器，即“线控（by-wire）”。核心三大件：

🎯 线控转向

方向盘与转向机之间没有机械硬连接（或保留离合器作为后备），由电机按控制指令转向。好处是响应快、可精确到 0.1°，还能隔离路面抖动。

🛑 线控制动

用电机/液压单元代替驾驶员踩踏板。可分“舒适制动（日常减速）”与“紧急制动（全力刹停）”两档，响应时间从人的 0.5 秒量级缩短到毫秒级。

⚡ 线控驱动

电驱动天然适合精确控制：扭矩响应在毫秒级，电动车还能通过“扭矩矢量控制”辅助转向稳定性。

除三大件外，自动换挡、电子驻车、灯光与喇叭也需能由系统直接控制。L3+ 车辆还要求这些子系统具备独立冗余通道——电子转向失效时，备份电机/液压仍能完成靠边停车。

03

控制算法家族

算法思路特点与用途
PID按误差的比例、积分、微分输出控制量简单、工程常用；但难处理强耦合与大惯性，常加前馈提高响应
前馈 + 反馈按轨迹曲率“提前”给控制量，再按偏差修正弯道不滞后；横向控制的主流工程框架（如 Stanley、LQR 类）
MPC 模型预测控制用车辆模型预测未来一段状态，滚动求解最优控制序列能显式处理约束（加速度限值、转向限位），适合横向+纵向联合控制，算力要求高
滑模/鲁棒控制设计滑模面使状态快速收敛抗参数摄动与外界扰动（侧风、坡度）研究常用

纵向控制（速度/车距）则常拆成两层：上层根据前车距离与目标车速计算“期望加速度”（类似 ACC 的逻辑），下层由驱动/制动协调器决定油门与刹车如何分配，避免“又踩油门又踩刹车”的抖动。

04

车辆模型：从运动学到动力学

控制器必须内置“车辆会怎么动”的模型。低速场景（泊车、末端配送）可用运动学自行车模型：状态为后轴中心 (x, y)、航向 θ、速度 v，控制量为前轮转角 δ 与纵向加速度 a；高速时轮胎侧偏不可忽略，必须用含横摆角速度与侧偏刚度的动力学模型。经验准则是横向加速度 |a_y| < 0.3·g 时可近似用运动学模型。

05

轨迹跟踪：让车沿着“看不见的轨道”走

规划轨迹是一条虚拟轨道，控制要解决的典型问题包括：

  • 横向跟踪：车与参考线的横向偏差、航向偏差如何通过转向角消除（弯道需要根据曲率预打方向，即前馈项）；
  • 纵向跟踪：实际速度与期望速度的偏差，通过加减速消除，并考虑坡度（上坡多给扭矩、下坡靠制动/能量回收）；
  • 联合控制：高速急弯时“先减速后转向”能显著提升稳定性与舒适性，这需要横纵向解耦或 MPC 联合优化；
  • 执行器延迟补偿：转向电机、液压制动都有几十毫秒延迟，控制律需预测补偿，否则高速下会振荡。

评价控制好坏的三组指标：跟踪精度（横向误差 < 10cm 级）、平顺性（加速度变化率 jerk 尽量小）、鲁棒性（雨雪湿滑、载荷变化、轮胎磨损下仍稳定）。

06

执行层的冗余与故障降级

对 L3+ 而言，执行器是安全关键部件，必须遵循功能安全（ISO 26262，最高 ASIL-D 等级）设计：

🔁 双通道冗余

转向有主/备份电机，制动有双回路液压或“电子制动 + 机械驻车”后备，电源与通信总线也做冗余，做到“单点失效不影响安全”。

📉 分层降级

轻度异常 → 限制性能继续行驶（限速）；中度异常 → 请求驾驶员接管；严重异常 → 独立的安全监控单元直接接管，执行“减速靠边停车”。

这套“降级剧本”与决策规划中的最小风险策略协同：规划负责“去哪停”，执行冗余负责“还能不能打方向和刹车”。两者缺一不可，详见 功能安全专题。

07

不同车型的差异

车型控制难点
乘用车追求平顺与低速精准（泊车、窄路），底盘成熟、供应商选择多
干线重卡车长、轴距大、制动距离长、载重变化剧烈，横向控制需要专门的挂车/鞍座模型
矿区宽体车重载、路面颠簸扬尘、坡度大，常需改造转向与制动系统，可靠性要求极高
末端配送车低速小车身，但要在人车混行的非机动车道穿行，制动的“果断性”比舒适更重要
08

标定参数与性能指标

控制效果最终体现为一组可测量的指标。下表给出乘用车常见工程参考区间（不同品牌标定差异很大，仅作量级参照）：

指标典型目标说明
横向跟踪误差稳态 < 10–30 cm弯道与曲率突变处允许更大瞬态误差
横向加速度 ay≤ 1–2 m/s²（舒适）紧急避障可短时超过，需与舒适性权衡
纵向加速度日常 ≤ 2–3 m/s²紧急制动可达 6–9 m/s²
jerk（加速度变化率）< 2–5 m/s³决定乘客是否感到“顿挫”，是舒适性核心指标
转向执行延迟100–300 ms需在控制律中补偿，否则高速下振荡
控制周期50–100 Hz低于 20 Hz 会明显影响跟踪品质

标定通常在“仿真回归 → 封闭场地（ISO 3888 双移线、ISO 4138 稳态回转）→ 公开道路”三级完成，并用统一的数据采集与指标计算脚本保证可复现。

09

常见疑问

线控转向失效了怎么办？

量产方案保留“机械冗余”：正常时电控转向，故障时通过离合器恢复机械连接，让驾驶员（或冗余电机）接管。L4 无人车没有驾驶员，则必须配置双套转向驱动，或保证失效时能安全停车并等待远程介入。

为什么刹车要分“舒适”和“紧急”两套？

全力制动会带来 1g 以上减速度，既不舒适也可能引发后车追尾。日常减速用能量回收+缓刹；紧急情况则由 AEB/安全监控独立触发全力制动——两套逻辑互不干扰，避免“该缓时急刹、该急时犹豫”。

自动驾驶怎么处理爆胎、制动衰退这类极端故障？

通过底盘状态监测（胎压、制动温度、横摆角速度对比）识别异常，然后：限制车速 → 请求接管或驶向安全区 → 必要时用“差动制动”维持方向（如爆胎时单侧制动纠偏）。这是功能安全里典型的“失效可控制”场景。
